# 婚礼用品清单 · 完整源码包

## 文件说明

- `index.html`：网页入口。
- `styles.css`：配色、字号、响应式布局。
- `app.js`：编辑、增删、状态切换、搜索、筛选、导入导出和本地保存。
- `data.js`：首次访问时载入的原始清单，共 41 项。
- `data.json`：相同清单的 JSON 备份，可在页面导入。
- `assets/`：原表内的窗帘、四件套参考图。
- `单文件版.html`：所有代码、数据和图片内嵌的独立版本。

## 运行

解压后用现代浏览器打开 `index.html` 即可使用，无需安装依赖。
也可在源码目录运行：

```sh
python3 -m http.server 8000
```

然后打开 http://localhost:8000 。

## 功能

保留原表 41 项内容、3 个分类、数量、备注、原表标记和 2 张参考图。
支持新增、删除、编辑物品与备注，切换已选定和已购买状态。已购买条目置灰。
支持搜索、分类和状态筛选，导入 XLSX/CSV/JSON，导出 JSON 备份。
XLSX 导入使用浏览器解压功能，并读取首个工作表；旧浏览器可改用 CSV/JSON。

## 修改源数据

修改 `data.js` 中对应条目即可改变首次打开时的清单。`data.json` 是另存的备份，修改后如需保持一致，请同步更新。
浏览器已有保存记录时会优先读取该记录。可通过页面导入更新后的 JSON，或清除站点存储重新载入初始数据。
`单文件版.html` 是当前版本的独立快照，修改拆分源码不会自动同步到它。

## 公开部署

这是纯静态项目。将本目录全部文件上传到支持静态网站的托管服务，以 `index.html` 为入口即可。构建步骤为空，无服务端依赖。
本代码包不包含已经成功上线的公开网址，也不包含账户凭证。

## 数据保存范围

页面编辑保存在当前浏览器的 localStorage 中。公开网址上的不同访问者各自保存修改，修改不会自动同步到其他人的设备。
换设备前可点击“导出备份”，再在新设备导入 JSON。若需要多人共享同一份实时清单，还需接入后端数据库和编辑权限。
